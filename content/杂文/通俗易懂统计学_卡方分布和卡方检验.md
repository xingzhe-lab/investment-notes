通俗易懂统计学|卡方分布和卡方检验

假如你每年做一次体检，检查10项指标（血压、血糖、胆固醇等）：

- 每项指标都有标准参考值（μ）和正常波动范围（σ）

- 对于每项指标，你可以计算一个 Z分数：Z = (你的值 - 参考值) / σ

- 如果Z接近0，表示你的这项指标很正常

- 如果|Z|很大，表示你的这项指标偏离正常很远

- 现在，你想知道整体健康状况：总偏离度 = Z₁² + Z₂² + ... + Z₁₀²

- 这个"总偏离度"的分布就是卡方分布

这个总偏离度越大，说明你整体上越不健康（多项指标异常）。卡方分布就是告诉我们，在"完全健康"的假设下，这个总偏离度的概率分布是怎样的。

数学定义

如果k个相互独立的标准正态随机变量Z₁, Z₂, ..., Zₖ（每个都服从N(0,1)），那么它们的平方和：

Q = Z₁² + Z₂² + ... + Zₖ²

服从自由度为k的卡方分布，记作Q ~ χ²(k)。

来看看R语言代码生成不同自由度的卡方分布

#加载R包

library(ggplot)

# 设置随机种子，确保结果可重复

set.seed(123)

# 生成不同自由度的卡方分布随机数

df_values <- c(1, 2, 3, 5, 10)  # 不同的自由度

n_samples <- 10000

# 创建数据框存储模拟数据

chi_data <- data.frame()

for (df in df_values) {

chi_samples <- rchisq(n_samples, df = df)

chi_data <- rbind(chi_data,

data.frame(

value = chi_samples,

df = factor(paste("df =", df),

}

当自由度越大，卡方分布就趋近于正态分布。

- 正态分布：就像测量一群人的血压值，大部分集中在正常范围，两端较少

- 卡方分布：就像比较观察到的病人恢复情况与理论预期之间的差异平方和

- t分布：就像在小样本情况下估计新药平均效果时的不确定性

- F分布：就像比较两种不同治疗方案的方差（波动程度）

关键关系：

- 卡方分布是正态分布的平方和：如果从正态分布中取多个独立样本，平方后相加，就得到卡方分布

- t分布来自正态和卡方的结合：t = 正态分布变量 / √(卡方分布变量/自由度)

- F分布是两个卡方分布的比值：F = (卡方1/自由度1) / (卡方2/自由度2)

卡方检验：用于分类变量的关联性检验

比如，对照和病例之间某个等位基因的频率比较，或某个药物的治疗效果评价（有效vs 无效）等

#创建一个2*2列联表

treatment_data <- matrix(c(45, 15, 30, 30), nrow = 2,

dimnames = list(治疗 = c("新药", "安慰剂"),

效果 = c("有效", "无效")))

print("治疗效果的列联表：")

print(treatment_data)

# 执行卡方检验

chi_test <- chisq.test(treatment_data)

print("卡方检验结果：")

print(chi_test)

结果解读：(1) 卡方统计量 (X-squared)

- 含义：衡量观察值与理论值之间的总差异

- 数值越大，实际观察与理论预期的差异越大

- 公式：Σ[(观察值-期望值)²/期望值]

- 解读示例：6.9689 表示观察值与期望值有较大差异

(2) 自由度 (df)

- 公式：df = (行数-1) × (列数-1)

- 2×2表格：df = (2-1)×(2-1) = 1

- 3×2表格：df = (3-1)×(2-1) = 2

- 重要性：自由度影响卡方分布的形状和临界值

(3) p值 (p-value)

- 解读规则：

- p =0.008 < 0.05 → 差异有统计学意义

新药疗效与安慰剂存在显著差异。

还可以获得期望值和残差：

print(chi_test$expected)

print(chi_test$stdres)
