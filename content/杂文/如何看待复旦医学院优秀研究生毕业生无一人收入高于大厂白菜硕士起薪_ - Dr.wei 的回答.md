# 如何看待复旦医学院优秀研究生毕业生无一人收入高于大厂白菜硕士起薪_

如何看待复旦医学院优秀研究生毕业生无一人收入高于大厂白菜硕士起薪_ - Dr.wei 的回答

如何看待复旦医学院优秀研究生毕业生无一人收入高于大厂白菜硕士起薪? - Dr.wei 的回答

问题描述：

复旦医学院顶尖吧，博士生学历顶尖吧，优秀毕业生顶尖吧，不过这里面所有人感觉没有一个收入（最高估计也就是那个香港博后大概35万）能比大厂底层211白菜硕…

曾经看到过一句话：如果一个行业的人越老越吃香，那么这个行业的年轻人可能在“吃屎”。

我瞬间想到了医疗行业。

调侃归调侃，从大学毕业到现在这十多年来，期间舆论吐槽医生收入低的声音从来没断过，但真转行的也没多少，大家似乎都是“一边吃屎一边幻想着未来吃香喝辣”。

同样，知乎、抖音等自媒体上的很多医学类博主和年轻医生，也不断向外界输出情绪，通常是吐槽，并且出了好多网红，其中相当一部分人，就是吃“吐槽医学行业、贩卖行业焦虑”这碗饭的。但这对于认清周围世界，以及改善自身处境并没有太多意义。

教员爷爷说过：牢骚太盛防肠断，风物长宜放眼量。

长者爷爷说过：一个人的命运固然要靠个人奋斗，但也要考虑历史的进程。

我现在把这两句话奉为圭臬。

如果能跳出医学圈子，多找机会体验一下其他行业，你会发现绝大多数职业其实都遵循一致的价值创造曲线：

1、职业生涯早期（成长期）：你的价值 = 时间 + 体力 + 基础技能。

2、职业生涯中期（成熟期）：你的价值 = 专业技能 + 解决问题的能力。

3、职业生涯后期（转型期）：你的价值 = 判断力 + 资源整合能力 + 领导力 + 影响力。

绝大部分职业都是这么走过来的（甚至妓女，小偷等职业一样如此）。只不过每个阶段之间的转变绝非易事。

先拿我经历过的一些兼职体验举例子。

我学生时代赚到的第一桶金是医学教育/出版/编辑类。当时刚考上研究生，由于是专业课第一名，被某个比较有名的考研机构请去给VIP做一对一培训，回想起来，那时候自己赚的本质上还是职业生涯早期的辛苦费，因为没有平台资源，也缺乏整合能力，所以我的价值就只能是讲课本身。这期间为了多挣点学费，也接一些出版的活，基本纯体力劳动（比如校对、编辑等），主要还是学生时代时间多，缺钱，现在再挣这样的辛苦钱，肯定没时间了。

后来慢慢在业内有点名气，加上后来读博做博后，人设也上去了，越来越多的机构请我去讲课，这时候人家给的劳务费也多起来，这里面除了辛苦费，还有一部分属于“对专业技能的认可”。

再后来，机构的经理提出让我带团队，价钱自己定。这时候，我的价值就不只是时间和专业技能了，还包括判断力、资源整合能力、领导力等综合因素。但是我在这一步上权衡了一下：如果带团队，基本意味着要牺牲大部分科研时间，可能不会拿到硕博士学位，最后将带团队的事转给了一个同学。

所以，我可以说在转型期主动放弃（也算失败），也因此错过了一次风口，毕竟当时这个赛道是出过很多类似张雪峰这样的网红。

再看看身边的例子，一个是发小，一个是表姐夫。

发小第一学历并不高（大专），当初学的网页设计，赶上了互联网时代红利，先是跟着一个日本团队做项目，后来自己熟悉以后开了公司，在我还读书的时候，他已经买房买车。他属于从起步期到成熟期转型非常快，唯一代价就是秃头。表姐夫是985本科，毕业就入职华为，从基层一直做到部门经理，属于三个阶段都完整的走了一遍，代价是几乎没回过家。

还有两个朋友是日语翻译，也都是大专学历，主要做日本旅游市场。这两位大佬在90年代，周围平均工资两三千的时候，他们月薪已经五位数。于是后来自己开文旅公司，通过积攒的人脉、资源做起来了。

通过这几个人你的职业轨迹，你可以发现，虽然大家的起点参差不齐，早期阶段的经历或长或短，但是都有一个共同点，那就是最后能顺利升级到成熟或转型。

大家不要觉得成熟或转型是每一种职业的必然。实际上，职业的发展规律并不代表个人就一定能达到相应的阶段。

比如一个汽车修理工，如果只会修车，不研究汽车发展的新变化，不分析行业发展的趋势，那么他大概率会长期停留在初级阶段，如果他能主动提升技能，或者搞资源整合，才可能成为一名汽车工程师，或者汽修店老板。

此外，有些职业属性，会天然限制个人上升到高阶段。如果你想转型，可能就要和原来的职业脱钩，医生就是一个典型的例子。比如贺银城，他如果一直当医生，就没有后来的医学教育产业。

就个人观察，医生停留在成长期、成熟期的较多，最多是通过专业技能获得高额回报，但能转型升级的则是个例，比如某些大佬涉足私人医药领域或者其他赛道获得回报。

总结下来，我从医学这个职业，看到了关于收入曲线的一些规律：

1、职业生涯不同阶段，决定收入的核心因素不一样

很多时候，收入不直接与辛苦程度（劳动时间）挂钩，而是与你所在职业的市场需求、技能稀缺性，以及行业垄断程度挂钩。

在成长期，你只能出卖时间、体力（广义上也包括姿色），除此以外缺少溢价能力。

在成熟期，你可以通过掌握稀缺技能获得溢价，甚至你会因为害怕后来者快速掌握稀缺技能，人为控制后来者的成熟时间（想想看，规培、专培、晋升等是不是这个道理）。

在转型期，你不再受限于体力、时间、专业技能等的限制，而是通过拥有稀缺的视野、经验、资源、人脉、渠道、平台等获得高回报。

比如现在医学界，由于规培制度，导致处于职业成长期的医生供大于求，这就决定了复旦医学院的研究生也无法获得较高回报。但是大厂硕士，甚至本科生能拿到高薪，往往也是所处的平台“替他们”掌握某些稀缺资源，因此自身也获得了相应的溢价。

2、从“人力资本”到“金融资本”的转变，困住了大部分医生

职业生涯前半段，医生的主要投入和增值源于自身“人力资本”（知识、技能、健康）。

职业生涯后半段，则要将积累的“人力资本”逐步转化为“金融资本”（资产、投资），让钱为你工作，实现收入的多元化。但这一步很多医生难以做到，这里有专业、政策、法律等多方面的原因。

同样，大厂程序员们，如果不能在成熟期之后抓紧转型，必然面临后来者的挑战，而医生可以在成熟期较为安全地生活几十年。

3、不可避免的周期性与瓶颈

所有职业其实都会遇到平台期。突破瓶颈需要主动求变，无论是通过跨界学习、拓展人脉、改变赛道，还是创业。但是在这一点上，很多医生其实很难接受这样一个现实，那就是：没有人能一直处于收入巅峰。

也就是说，哪怕做医生，也必须珍惜能挣钱的时间，多挣一些，多攒一些，少折腾，给自己留好后路，因为谁也不知道，哪天政策风向变化，未来还能不能维持以前的高收入。

所以，我们大部分一辈子都只是打工人而已，一味比较医生和程序员之间的收入差距，只能说明我们的境界还是太低了。
