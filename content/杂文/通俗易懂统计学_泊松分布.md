通俗易懂统计学|泊松分布

在前面的内容中我们介绍了和二分类变量有关的二项分布和负二项分布，今天我们来介绍一下和计数资料有关的分布，也就是离散变量分布中应用也非常多的泊松分布。泊松分布通常用来描述单位时间或者单位空间内的罕见事件随机发生的次数的概率分布。

![image](https://raw.githubusercontent.com/xingzhe-lab/investment-notes/main/static/essays/a8795280a28e969fbb31.gif)

符合泊松分布的随机变量的平均值和方差相等（为lamda），这是判断一个随机变量是否符合泊松分布的充要条件。

生命科学中常见的例子血液里的白细胞的计数，平板克隆的计数，发病数，每毫升水中的细菌数等等，这些随机变量的分布都可以用泊松分布来模拟。

泊松分布，就是用来预测“罕见事件”在“固定范围”内发生次数的概率分布。

这里的“罕见事件”是指它不常见、偶尔发生。

固定范围就是，某个空间或者某个时间。

例如，你在一家医院的急诊科值夜班。

- 固定范围：你值的这个班，比如 晚上8点到早上8点，共12个小时。

- 罕见事件：前来就诊的急症病人。病人不会扎堆来，也不会一直不来，而是随机地、一个一个到来。

现在，主任问你一个问题：

“根据历史数据，我们急诊室平均一晚会来 4个病人 (λ = 4)。那么请问，今晚恰好来 3个病人 的概率是多少？来 6个 的概率呢？一个病人都没有的可能性有多大？”

这个时候就可以用我们上面提到的泊松分布的概率公式来计算了。

一个事件能不能用泊松分布来研究，要看它是否满足以下特点：

- 事件是独立的：一个病人的到来，不影响下一个病人到来的概率。他们彼此之间是独立的。

- 事件以已知的平均速率发生：你知道在固定时间段内，事件发生的平均次数（λ，读作“lamda”）。在我们的例子里，λ = 4（人/晚）。

- 事件在任意时间点发生的概率是相同的：在晚上9点来病人的概率，和凌晨3点来病人的概率，理论上是一样的。

当然除了公式，我们也可以用R代码来计算。

和别的分布函数类似，也有四个泊松分布相关的函数（分别以d，p，q，r四个字母+pois表示），

- dpois()：计算特定值的概率（概率质量函数）

- ppois()：计算累积概率（累积分布函数）

- qpois()：计算分位数（分位数函数）

- rpois()：生成随机数（产生符合泊松分布的随机数）

可以通过以下代码获得各个函数的说明文档。

# 查看泊松分布相关函数

?dpois

?ppois

?qpois

?rpois

例如，假设急诊室每小时接诊的患者数平均为2.5个，我们可以用R语言的代码来展示急诊室每小时接诊的患者数分布：

# 急诊室每小时患者到达数

emergency_data <- tibble(

patients = 0:10,

probability = dpois(patients, lambda = 2.5)

)

ggplot(emergency_data, aes(x = patients, y = probability)) +

geom_col(fill = "lightblue", alpha = 0.7) +

geom_line(aes(y = probability), color = "darkblue", size = 1) +

labs(title = "急诊室每小时患者到达数分布",

subtitle = "泊松分布 (λ=2.5)",

x = "患者数量", y = "概率") +

theme_minimal()

λ 是泊松分布中唯一需要知道的参数，它代表了事件发生的平均强度。

- λ 很小（比如 1）：意味着事件非常稀有。概率分布图会集中在左侧（0，1，2次），说明大概率什么事都不会发生或只发生一两次。

- λ 增大（比如 5）：事件变得频繁一些。分布图会向右移动并铺开，形状开始变得对称。

- λ 很大（比如 10）：分布图看起来会越来越像我们熟悉的“钟形曲线”（正态分布,在以后的帖子中将介绍）。
