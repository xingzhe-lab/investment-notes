第一部分：变量与随机变量

1. 什么是变量？

想象一下你在填写一份调查问卷：

- 你的年龄：可以填18、20、23等。

- 你最喜欢的颜色：可以选“紫色”、“粉色”、“绿色”等。

- 你对某个课程的满意度：可以选“非常不满意”、“不满意”、“一般”、“满意”、“非常满意”。

这里的年龄、颜色、满意度就是变量。简单来说：

变量就是一个可以变化、可以取不同值的量。 它是我们想要观察或测量的东西。

2. 什么是随机变量？

现在，我们把“变量”这个概念放到一个不确定的、有随机性的场景里。

核心思想：随机变量是一个其数值由某个随机事件的结果决定的变量。

它就是一个映射，把一个随机事件的结果，转化成一个具体的数字。

随机事件的所有的可能的结果的集合就叫样本空间 ，随机变量就是对应在样本空间上的实值单值函数。

例子1：抛硬币

- 随机事件：抛一枚硬币。

- 可能结果：正面、反面。

- 定义随机变量X：我们规定，如果结果是正面，X就取值为 1；如果结果是反面，X就取值为 0。

- 所以，随机变量 X 的可能取值是 {0, 1}，也叫样本空间，但具体是0还是1，在抛之前是不知道的，取决于随机的结果。

例子2：掷骰子

- 随机事件：掷一个骰子。

- 可能结果：1点、2点、3点、4点、5点、6点。

- 定义随机变量Y：我们规定，朝上的点数是多少，Y就取值多少。

- 所以，随机变量 Y 的可能取值是 {1, 2, 3, 4, 5, 6}，具体是哪一个，在掷之前是不确定的。

例子3：医生在门诊看病

- 随机事件：看了一个病人。

- 可能结果：男性、女性。

- 定义随机变量X：我们规定，如果病人是男性，X就取值为 1；如果病人是女性，X就取值为 0。

- 所以，随机变量 X 的可能取值是 {0, 1}，但具体是0还是1，在病人来之前是不知道的，取决于随机的挂号的结果。

例子4：中午在某个饭店观察顾客点单

- 随机事件：来了一个顾客点单。

- 可能结果：煲仔饭、麻辣烫、炒面、炒粉、盖浇饭（假设这个店就这些分类）。

- 定义随机变量X：我们规定，如果顾客点的煲仔饭，X就取值为 1；如果点的是麻辣烫，X就取值为 0；如果点的是炒面，X就取值为-1；如果点的是炒粉，X取值为2；如果点的是盖浇饭，X就取值为 3。

- 所以，随机变量 X 的可能取值是 {-1,0,1,2,3}，但具体是哪个值，在顾客点单之前是不知道的，取决于随机的点单的结果。

如果我们想知道吃盖浇饭的人多不多，就可以通过计算点盖浇饭的概率来推算，把这个问题转化成数学问题P(X=3)。

总结：

- 变量：一个会变化的可测量或可分类的特征（比如“有没有得病”）。

- 随机变量：一个其变化是不确定的，随机的，它的具体值是不确定的，我们只能用概率来描述它取某个值的可能性，随机变量就是一个映射，一个函数，具有成对的对应关系 。可以把日常中的问题转化成数学问题。

第二部分：离散随机变量的分布——二项分布

随机变量的分布，根据随机变量的取值是不是有限的，分为离散随机变量和连续性随机变量。如果一个随机变量所有可能取到的值是有限个或可列的无限个（可以一个一个地列举出来），则称之为离散随机变量。

我们来介绍一个应用非常广泛的“随机变量”——服从二项分布的随机变量。

1. 特征

二项分布的应用场景：

假设你在重复地做同一件简单的事或者观察某个事件，这件事只有两种可能结果，而且每次做的结果都互不影响。你的问题是，在做了n次之后，其中一种结果总共出现了多少次。

2. 满足二项分布的条件

要使用二项分布，一个随机实验必须同时满足以下四个条件：

- 固定次数的试验 (n次)：你事先就知道你要做多少次。比如，抛10次硬币，调查100个居民。

- 每次试验只有两种结果：成功 vs. 失败。这里的“成功”不是字面上的意思，是指你关心的那个结果。比如：

- 抛硬币：正面（成功） vs. 反面（失败）

- 是否患病：患病（成功） vs. 不患病（失败）<-- 这里“成功”指的是我们关心的“患病”人数。

- 每次“成功”的概率保持不变 (概率为p)：每次试验中，“成功”的概率p保持不变。比如，抛一枚公平硬币，每次出现正面的概率p永远是0.5。

- 各次试验相互独立：任何一次试验的结果都不会影响其他试验的结果。比如，你第一次抛硬币是正面，不会影响第二次抛是正面还是反面。

3. 二项分布“三要素”

如果一个随机变量X服从二项分布，我们把它记作 X ~ B(n, p)。

- X：这个随机变量本身，它代表的是 “n次试验中，成功的总次数”。

- n：总的试验次数。

- p：每次试验中“成功”的概率。

4. 概率计算公式、“平均水平”和方差

- 概率公式：如果 X ~ B(n, p)，那么它恰好成功k次的概率为：P(X=k) = C(n,k) * p^k * (1-p)^(n-k)

- 期望值（平均水平）：一个服从二项分布的随机变量X，它最可能出现的“平均水平”是多少呢？期望 E(X) = n * p

- 假设在某次考试中80分以上的概率是0.7，调查了10个同学，期望有多少个在80分以上，E(X) = 10 * 0.7 = 7。

- 一个服从二项分布的随机变量X的方差：Var = n * p* （1-p）

总结

- 二项分布：是一种描述 “多次重复做或观察一件只有两种结果的独立事件，其中一种结果发生次数” 的概率分布。

- 满足条件：固定次数(n)，两种结果，恒定概率(p)，相互独立。

- 问题举例：“抛10次硬币，出现6次正面的概率？”、“调查100个老年人，发现10个高血压患者的概率？”

- 平均水平：如果重复实验很多很多次，平均的“成功”次数是 n * p。

- 方差：一个服从二项分布的随机变量X的方差为n * p* （1-p）

第三部分：用R语言来展示二项分布

给数据画图就像是给人拍照，能对抽象的数据有一个直观的印象。

我们来看看符合二项分布但“成功”的概率不同的随机变量X的概率分布。

# 比较不同成功概率的二项分布

probabilities <- c(0.1, 0.5, 0.9)  #设置不同的概率

n_trials_comparison <- 20   #设置试验次数n

# 生成数据

comparison_data <- data.frame()

for (p in probabilities) {

temp_data <- data.frame(

successes = 0:n_trials_comparison,

probability = dbinom(0:n_trials_comparison, size = n_trials_comparison, prob = p),

p_value = paste("p =", p)

)

comparison_data <- rbind(comparison_data, temp_data)

}

# 绘制图

library(ggplot2)

ggplot(comparison_data, aes(x = successes, y = probability, fill = p_value)) +

geom_col(alpha = 0.7) +

facet_wrap(~ p_value, ncol = 1) +

scale_fill_manual(values = colors)+

labs(title = "不同成功概率的二项分布比较 (n=20)",

x = "成功次数", y = "概率") +

theme_minimal() +

theme(legend.position = "none") +

scale_x_continuous(breaks = 0:n_trials_comparison)
