通俗易懂统计学|正态分布

正态分布是统计推断的基石，也叫高斯分布。几乎所有的参数统计方法，例如

t检验和方差分析等，其核心前提都是“数据服从正态分布，或样本量足够大以满足中心极限定理”（后面会介绍这个定理）。

正态分布就像一个模板——大部分人的身高都落在平均值附近，特别矮和特别高的人很少。很多测量数据（如血压、血糖、血红蛋白浓度、身高）都符合这种“中间多，两边少”的分布规律。

1. 关键特征

- 形状：像一个对称的钟形。

- 中心：峰值对应的是平均值（mean, μ）。

- 分散程度：标准差（σ）决定这条曲线是扁平还是陡峭的。

- 对称：平均值左右两侧的形状是对称的。

2. 例子

假设我们测量1000名20岁健康男性的收缩压，得到：

- 平均值 μ = 120 mmHg

- 标准差 σ = 10 mmHg

那么在正态分布下：

- 大约68%的人收缩压在 110~130 mmHg（μ ± 1σ）

- 大约95%的人收缩压在 100~140 mmHg（μ ± 2σ）

- 大约99.7%的人收缩压在 90~150 mmHg（μ ± 3σ）

这叫作 68-95-99.7法则，是判断数据是否正常范围的常用方法。

3. 医学中的应用

很多“正常参考值范围”就是利用正态分布确定的。比如，实验室测出血清钾的参考范围是3.5–5.0 mmol/L，这个范围通常是取健康人群数据的中间95%（即去掉最低2.5%和最高2.5%）。？

1）解读化验单：知道“正常值”是怎么来的。

2）理解流行病学：许多生理指标都近似正态分布。

3）后续学习基础：t检验、ANOVA等统计方法都假设数据服从正态分布（或近似正态）。

4）临床决策：比如用3个“标准差”来判断某个测量值是否异常偏离。测量值与平均值的偏差超过3倍标准差的值。异常偏离的值首先我们要确认测量是不是没问题，其次再去分析可能的原因，例如病人的病情特别严重，可能这个值就会特别高或者特别低。

4. 注意！不是所有医学数据都是正态分布

有的数据不是符合正态分布的，比如：

- 住院天数（通常右偏）

- 某些生化指标在特定疾病人群中的分布

- 生存时间数据这时候需要其他统计方法处理。

#生成正态分布数据并绘制直方图

# 生成1000个服从正态分布的数据（平均值为0，标准差为1）

set.seed(123)  # 设置随机种子，确保结果可重复

data <- rnorm(1000, mean = 0, sd = 1)

# 绘制直方图

hist(data,

breaks = 30,  # 设置30个柱子

col = "lightblue",

border = "white",

main = "正态分布直方图 (n=1000, mean=0, sd=1)",

xlab = "数值",

ylab = "频率")

# 添加理论上的正态分布曲线

curve(dnorm(x, mean = 0, sd = 1) * 1000 * diff(hist(data)$breaks)[1],

add = TRUE, col = "red", lwd = 2)

# 添加均值线

abline(v = mean(data), col = "darkgreen", lwd = 2, lty = 2)

legend("topright", legend = c("实际数据", "理论曲线", "均值"),

col = c("lightblue", "red", "darkgreen"),

pch = c(15, NA, NA), lty = c(NA, 1, 2))

不同参数的正态分布对比

# 生成三种不同参数的正态分布

set.seed(123)

data1 <- rnorm(1000, mean = 0, sd = 1)    # 标准正态分布

data2 <- rnorm(1000, mean = 2, sd = 0.5)  # 均值右移，sd更小更集中

data3 <- rnorm(1000, mean = -1, sd = 2)   # 均值左移，sd更大更分散

# 绘制密度曲线对比

plot(density(data1),

main = "不同参数的正态分布对比",

xlab = "数值",

ylab = "密度",

col = "blue",

lwd = 2,

xlim = c(-8, 6),

ylim = c(0, 0.8))

lines(density(data2), col = "red", lwd = 2)

lines(density(data3), col = "darkgreen", lwd = 2)

# 添加均值的垂直线

abline(v = c(0, 2, -1),

col = c("blue", "red", "darkgreen"),

lty = 2, lwd = 1)

legend("topright",

legend = c("N(0,1)", "N(2,0.5²)", "N(-1,2²)"),

QQ图检验数据是否服从正态分布

# 生成数据并检验正态性

set.seed(789)

normal_data <- rnorm(100, mean = 50, sd = 10)  # 正态数据

nonnormal_data <- rexp(100, rate = 0.1)        # 非正态数据（指数分布）

# 绘制QQ图

par(mfrow = c(1, 2))  # 并排显示两个图

qqnorm(normal_data, main = "QQ图 - 正态数据")

qqline(normal_data, col = "red", lwd = 2)

qqnorm(nonnormal_data, main = "QQ图 - 非正态数据")

qqline(nonnormal_data, col = "red", lwd = 2)

# Shapiro-Wilk正态性检验

cat("正态数据检验：\n")

print(shapiro.test(normal_data))

cat("\n非正态数据检验：\n")

print(shapiro.test(nonnormal_data))

par(mfrow = c(1, 1))  # 恢复单图显示
