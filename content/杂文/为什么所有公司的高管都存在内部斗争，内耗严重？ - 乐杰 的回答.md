# 为什么所有公司的高管都存在内部斗争，内耗严重？

目前在的一个公司，领导高管之间的斗争真的好比宫斗剧，小到部门领导，大到公司层面更换频繁，为什么所有公司的高管都存在内部斗争，内耗严重？为什么不能共谋公…

嘉靖说：朝廷也就是几座宫殿几座衙门罢了，饭还是分锅吃的。

内斗你看《1566》严党vs清流就明白了，高管不是想斗，而是制度逼他们斗。

严党和清流表面上都在为国家操心、讲道德，实际斗得你死我活。原因只有一个：有限的资源、有限的权力、有限的升迁名额，逼每个人不得不争。

你现在看到的不是性格问题，而是权力生态决定的必然结果。

一、你以为的企业高管，是战略合作者。

但真实的企业高管，是利益集团代表。

你会问：为什么不能共谋公司发展？对个人不是更好吗？

你还是把高管看成公司的人，而不是利益的节点。

《大明王朝1566》里严党 vs 清流是怎么斗的？

为了国家吗？

为了百姓吗？

错。

他们斗的是但凡关乎自己派系利益的一切：人、资源、政策、话语权。

公司高管的逻辑一样：每个高管都有自己的人、每个高管掌握的资源不同、每个高管对未来的公司路线有不同最优解、每个高管背后都有不同利益共同体。

所以他们不是同事，而是派系。

你憧憬的共谋发展，只有一个前提：目标完全一致，利益完全一致。

而现实中这两个前提永远不可能满足。

二、为什么高管之间一定会斗？

我们用《1566》的结构来复盘一下你明白了。

1、组织内的权力是有限资源，必然零和。

就像严党与清流，一个上升就意味着另一个下降，这个不是一个人的上升和下降，是两个利益集团的所有人位置的变动。

在公司里：

一个高管的预算多了，另一个就少了。

一个业务线扩张，另一个会被压缩。

一个得CEO信任，另一个信任度就相对下降。

你老板哪怕不想让他们斗，也没用；权力的总量固定，斗争的总量就固定。

有限的官位，有限的资源，于是人人必须争。

企业一样：你不争，你就会被别人争掉。

《大明王朝1566》里最典型的权力象征是什么？

不是海瑞的清廉，也不是嘉靖的城府，而是那两个决定所有官员命运的制度：京察和考成法。

① 京察：三年一次的大筛子。

京察是明朝特有的官员大考核，三年一次，全国官员全部排队，根据表现分成：能升、能留、该降、该滚。

最关键的是：“能升”的名额是有限的，“能留”也是有限的。

换句话说：你升了，就意味着别人升不了；别人被贬，你才有空间上来。

所以京察不是考核，是资源分配。

它逼着所有官员都去争、去拉帮结派、去站队。

这就是有限资源 → 必然竞争的制度根源。

![image](https://raw.githubusercontent.com/xingzhe-lab/investment-notes/main/static/essays/e4855dc16093edd434a3.jpg)

alt="Image">考成法祖宗在此

② 考成法：把所有人绑在一条线上比拼。

考成法的核心是：每一项政绩都要量化、排名，并直接决定官员的去留。

比如粮税、钱粮、灾情、赋役，只要指标完不成——降职、问责、停俸、连坐，统统来了。

这个制度的可怕之处在于：

资源有限：比如某地赋税就那么多。

任务硬性：每个人都要完成指标。

指标互相挤压：你完成了，别人就不够了。

因此，考成法把官员逼成了敌人：别人政绩好，你就危险；别人上去了，你就得下来。

这就是为什么《1566》里人人都在斗：制度天然地把人摆到对立位置上。

③ 把视角拉回企业。

现在你看企业高管的斗争，会突然明白：企业的预算、名额、战略项目，本质就是现代版的：

京察名额（能升谁？能留谁？）

考成指标（谁的业绩更亮眼？谁能保位？）

所有资源都是有限的：一个项目给A，就意味着不给B；一个预算给技术，就意味着不给市场；一个战略倾向某位高管，另一位就自动边缘化。

你不争，你的资源就会被别人争掉。

你不站队，你的地盘就会被别人蚕食。

你不抢指标，你的团队下年就没预算。

这不是人坏，这是公司制度结构逼你斗。

正如《大明王朝1566》里那句贯穿始终的权力逻辑：有限的官位，有限的资源，于是人人必须争。

公司亦是如此。

2、高管的权力来源不同，导致认知路线冲突。

在《1566》里：

严党代表皇帝的集权路线；

清流代表士大夫的清议路线。

他们即使都忠于国家，也不可能在路线问题上妥协。

把这个映射到企业：技术派认为产品创新最重要、市场派认为销售转化最关键、财务派认为成本可控是生命线、人力派认为组织能力决定未来、运营派认为执行系统才最要命。

每个高管看似都为了公司，实则都认为自己的路线才是对公司最有利。这些路线冲突，本质上不可调和，如同《1566》里严党清流谁也说服不了谁。

3、利益结构不透明，导致权力游戏必然黑箱化。

明朝的权力结构本质是：上有嘉靖皇帝的绝对权威，下有严嵩体系的利益网络，中间靠清流的道德话语权穿插博弈。

企业也是三层结构：

CEO = 皇帝（资源与裁决最终权）。

核心高管 = 严党/清流（控制真实的组织运作）。

基层员工 =基础官员（被影响的执行端）。

高管之间的斗争，本质是争取CEO这——皇权倾向谁。

你看到的所有争权、甩锅、排挤、拉帮结派，都是围绕：谁更接近CEO、谁掌握更多立项、谁能控制更多预算、谁掌握关键资源（人才、渠道、客户）。

它不是宫斗剧，而是权力生态的自然形态。

4、忠诚是最高价值，但忠诚必须通过斗争证明。

《1566》里严嵩最大的本事不是能力，是皇帝觉得他最听话。清流要生存，也必须不断证明自己忠于国家与天理。

你把这个镜头换成公司：高管要在老板面前立住脚，必须证明：我的路线没问题、我的人才最靠谱、别人的方案有隐患、我能守住你的战略方向、我能清除你看不见的风险。

你懂了吗？

斗争就是向老板证明忠诚的方式。

不斗的人 → 被认为 没存在感、不可靠、不站队。

斗得好的人 → 被认为 有担当、有力量、能扛事。

三、为什么斗争越严重，公司反而越换高管？

你观察非常精准：小到部门领导，大到公司层面更换频繁。

这是《1566》里嘉靖最典型的治理方式：均衡术 + 内斗驱动权力稳定。

CEO/老板也一样。

老板看到的不是你们斗不斗，而是：谁在斗争中表现出能力？谁在斗争中更忠诚？谁在斗争中暴露风险？

当一个派系过强，会威胁皇权（CEO），于是就会被换掉。

高管越换越频繁，说明老板越不信任任何一方。这不是混乱，而是老板的制度性策略。

最残酷的一点：公司发展并不是高管斗争的最优目标，你以为他们在想公司发展。

实际上多数高管的真实顺序是：

个人在公司生存；

派系利益稳定；

个人绩效与未来可迁移价值；

公司发展。

公司发展排第四，不是第一，你看《南明史》这本书特别能说明这点，国家尼玛都亡了，他们明明可以一致对外，但是他们就是不停的内斗最后被清庭逐一消灭。

原因非常简单：对他们而言，个人的位置是根基，而公司发展只是锦上添花。

公司倒了，他们跳槽还能当高管。但位置没了，他们什么都不是。

最后来说：高管不是共谋者，而是利益节点；组织不是合作场，而是权力场。

你在公司里看到的任何内耗、斗争、站队、换血，都不是异常现象——它们是体系天然运作的结果，就像《大明王朝1566》里严党与清流的斗争，是整个明代政治体制的必然产物。

企业就是小型的明朝权力场。

高管斗争不是为什么会发生，而是凭什么不会发生。

就像《大明王朝1566》那句最扎心的隐喻：不是因为人坏，而是因为公司的制度让他们只能这么活。
