一、万民英（明，《三命通会》作者）

八字：壬午 癸丑 庚寅 丙戌

生卒：1521—1603，享年82岁

字汝豪，号育吾，祖籍江夏，祖父迁居易州（今河北易县） 。

嘉靖二十八年（1549）中举，二十九年（1550）进士 。

历任：武进县令 → 河南道监察御史 → 巡按山海关 → 山东佥事 → 福建兵备参议（驻泉州） 。

人生大事

1. 抗倭有功：在泉州领兵剿倭，身先士卒，连破20余营，平定泉州倭患，威名大振。

2. 直言遭贬：上疏言边事，语多切直，得罪权贵，被构陷。

3. 归隐30余年：扶母灵柩回乡，不再出仕；建乡学、收弟子、设粥棚济贫 。

4. 著书传世：晚年著《三命通会》《星学大成》《易经会解》等，为明代命理、择日集大成者。

职业特点

为官刚直严明、实干能战；为学博综星命、体系化强 。

命理上兼擅子平与七政，重典籍、重实证，不尚空谈。

人生运程：

早年科场顺遂、仕途稳升；中年因言直遭忌、急流勇退。

后半生名位尽失、寿考绵长，以著书立说、教化乡里为归宿，福厚而权薄 。

二、张神峰（明，《神峰通考》作者）

八字：甲戌 庚午 乙亥 丁丑

生卒：1514—？，卒年不详

本名张楠，字神峰，号西溪，江西临川人。

儒医兼命理家：行医为生，同时精研子平术40余年。

人生大事：

1. 创立“病药说”：批评当时单纯讲中和、财官的片面论法，提出“先寻病、后下药”，以五行生克为核心，成为《神峰通考》灵魂。

2. 著《神峰通考》（又名《命理正宗》）：万历年间成书，强调月令格局、日主为体、病药为用，影响深远。

3. 医命双修：以医道类比命理，论命如诊病，处方如取用神，打通医理与命理。

职业特点：

书房派+实战派：重理论、重条理，不重神煞，纯五行论命。

文风直白通俗、口诀化强，便于流传，被后世视为“入门正宗”。

人生运程：

生平无高官显爵、无大灾大难，属于布衣宗师、以文传世的命格。

中年后名满江湖、弟子众多，以著书授徒终老乡里，寿考平稳。

三、任铁樵（清，《滴天髓任氏评注》作者）

八字：癸巳 戊午 丙午 壬辰

生卒：1773—1840，享年67岁

浙江人，出身书香世家、家境殷实，早年受良好私塾教育 。

20多岁遭骨肉之变，家产尽丧，从此以批命、代写书信、择吉为生 。

人生大事：

1. 家道中落、被迫从命：青年骤贫，生活极苦，遂专心命理，“穷则通命” 。

2. 批注《滴天髓》：耗时数十年，驳斥神煞、纳音、异格，纯以阴阳五行、旺衰平衡立论，逻辑严密，被尊为近代书房派祖师 。

3. 晚年成名、洛阳纸贵：50多岁后《滴天髓阐微》刊行，官宦、富商争相延聘，名动一时 。

职业特点：

纯理论派、重理不重术：弃神煞、弃纳音、弃奇格，专讲五行生克、日主强弱、格局用神 。

文风严谨深刻、哲理性强，被民国三大家（袁、徐、韦）奉为圭臬 。

人生运程：

早年富贵→骤贫，运势大起大落、苦不堪言 。

中年弃儒从命、厚积薄发；晚年名成利就、受人尊崇，但终身无官、以文名传世 。

四、袁树珊（民国，《命理探源》作者）

八字：辛巳 丁酉 乙巳 戊寅

生卒：1881—1952，享年71岁

江苏扬州人，医卜世家，父袁开昌为名医兼命理师。

早年考秀才未中，后入北京大学，留学日本东京帝国大学攻社会学。

归国后不仕，回乡半医半命；1930年后专事命理。

人生大事：

1. 民国命理“南袁北韦”之首：与韦千里齐名，达官贵人争相问命，包括蒋某石、何应钦、吴佩孚、马连良等。

2. 著《命理探源》《中西相人探源》：融合中西、理性客观，反对迷信，强调命理为“心理疏导+人生参考”。

3. 1949年移居香港，继续执业；晚年烧尽手稿、禁子孙从命，认为命理“泄天机、损阴德”。

职业特点：

文人命理、儒雅客观：不信鬼神、不搞玄虚，重逻辑、重经验、重人品。

医命兼通，论命温和、劝人为善，有“儒者之风”。

人生运程：

早年科举不顺、新学有成；中年名动公卿、财官两旺。

晚年避祸香港、看淡名利，寿考而终、子孙安稳。

五、徐乐吾（民国，《子平真诠徐氏评注》作者）

八字：丙戌 壬辰 丙申 丙申

生卒：1886—1948，享年62岁

浙江海盐人，出身世族，早年从政（任公务员），后弃官从命。

居上海执业，1940年代长驻香港六国饭店算命。

人生大事：

1. 民国三大家“南袁北韦中乐吾”：与袁树珊、韦千里齐名，书房派代表。

2. 评注子平经典：《子平真诠评注》《穷通宝鉴评注》《滴天髓征义》等，整理、校正、系统化子平理论。

3. 自评寿元极准：自断“六十一不死，六十三戊子必亡”，1948戊子年因心脏病卒，完全应验。

职业特点：

理论派、格局派：重月令格局、用神、旺衰，不重神煞，条理清晰。

文风简洁精准、断语干脆，批命后常署“姑妄言之”，态度谦和。

人生运程：

早年从政不顺、弃官从文；中年沪上成名、衣食无忧。

晚年移居香港、声名愈隆，但身体早衰、寿数已定，属于有才无官、文名传世之命。

六、林庚白（民国，《人鉴·命理存验》作者）

八字：甲午 戊辰 丁酉 庚戌

生卒：1897—1941，享年44岁

福建闽侯人，神童：4岁能文，7岁能诗，13岁考入京师大学堂（北大前身）预科。

1911年入同盟会，1912年入南社，政治家+诗人+命理家 。

人生大事：

1. 政坛活跃：历任众议院议员、宪法起草委员会秘书长、非常国会秘书长、立法院委员等 。

2. 诗名极盛：南社“诗怪”，自称诗才超杜甫，狂放不羁、名动文坛 。

3. 命理成名：著《人鉴·命理存验》，善断大人物：算准袁世凯死期、汪精卫结局；自断1941年横死。

4. 1941年香港遇袭身亡：太平洋战争爆发，在尖沙咀被日军枪杀，应验自断横死 。

职业特点：

狂才型、实战派：才华横溢、性格狂傲、敢断敢言 。

命理重实战、重应期、重神煞+五行，铁口直断、命中率高。

人生运程：

早年少年得志、一路开挂；中年政海浮沉、诗名鼎盛、命理成名 。

晚年凶煞临身、横死他乡，才华盖世、寿数短促、天妒英才。

七、韦千里（民国，《千里命稿》作者）

八字：辛亥 辛卯 庚子 庚辰

生卒：1911—1988，享年77岁

浙江嘉兴人，复旦中文系毕业，父韦石泉为上海知名命理师。

16岁父亡，弃海关“金饭碗”，挂牌算命，22岁出书成名。

人生大事：

1. 民国三大家“南袁北韦”：实战派第一人，达官贵人、明星名流络绎不绝。

2. 著《千里命稿》：1935年出版，条理清晰、案例丰富、通俗易懂，成为现代命理入门必读。

3. 西安事变断宋美龄：宋美龄问卜，韦断“可保平安、不久必和”，后果验，声名大噪。

4. 1949年移居香港，执业至晚年；李居明曾师从其门下。

职业特点：

实战派、江湖派+书房派融合：重五行、重格局、重神煞、重应期，断语直白、收费不菲。

文风通俗流畅、深入浅出，善用比喻、案例鲜活。

人生运程：

早年家道中落、弃官从命、少年成名。

中年沪上大红、财名双收；晚年香港安居、寿考而终、弟子满门。
