# 55《十亿美金的教训》深度解读（详细版）

> **副题：林军——"10 个中国互联网折戟沉沙的故事"：创始人内讧、热钱诱惑、雄心膨胀——为什么他们离十亿美金只差一步**
>
> 作者：林军，中国互联网历史写作者，著有《沸腾十五年》。本书选取 10 个中国互联网失败案例——**51.com、3721、ITAT、PPG、分众、港湾、联想FM365、联众、盛大盒子、8848**——每个故事的主角都曾离成功一步之遥，每个失败的价值都在十亿美金量级。
>
> **核心定位**：互联网版的"失败学"——"如果你能从这些教训中提前受益，做出正确选择，每一个案例的主角都能至少成就十亿美金公司。"与 [[40《避开股市的地雷》深度解读（详细版）|40 号张化桥"排雷"]] 形成"失败学双璧"——张化桥讲 A 股造假地雷，林军讲互联网创业天坑。
>
> **系列意义**：055 是系列第 55 本，**商业失败学篇**——补齐了"不做什么比做什么更重要"的完整维度。

## 案例一 51.com：内讧的代价

### 1.1 "中国最像 MySpace 的公司"——为什么死在腾讯手里

51.com 曾经是中国最大的社交网络之一，创始人庞升东被比作"中国的史玉柱"。但 2010 年 3 月，联合创始人张剑福以"健康原因"离职——实际上两人已彻底反目。

| 核心冲突 | 表现 |
|---------|------|
| 庞升东眼中 | 51 创办于 2005 年 5 月——他是主导者 |
| 张剑福眼中 | 起点是 2003 年他自己创办的 10770——**"我和这家公司有 7 年的缘分"** |
| 认知错位 | "庞升东眼中的张剑福，与张剑福对自己的认知并不重合" |
| 后果 | 管理团队不稳定、组织结构反复调整 |

> "创业团队的分崩离析，与十亿美金教训的形成虽然不是完全的充要条件，但两者之间关联甚大。一旦创业团队相互形成不了认可——业务就会出现问题，尾随而来的则是资本的压力和对手的步步紧逼。"

**在 51 内讧的同时，腾讯对 QQ 空间发力——让 51 彻底失去了超越的可能。**

### 1.2 教训

| 导致失败的因素 | 后果 |
|-------------|------|
| 创始人认知错位 | 谁也说服不了谁——决策分裂 |
| 团队流失 | 能人走了，剩下一盘散沙 |
| 对手乘隙 | 腾讯趁虚而入——"甚至把这种可能都扼杀了" |

> "51 的陨落不是因为产品不好——是因为两个创始人心里想的是两家不同的公司。"

## 案例二 3721：借力未遂——周鸿祎的"心痛"

### 2.1 "如果我有时光穿梭机……"

> "如果我有时光穿梭机，今天再回去做 3721——可能其他很多人的机会不会存在。我不仅可以把搜索这个市场拿下，很多事也可以做出来，只要你有一个强大的客户端。"——卖掉 3721 一直是周鸿祎心里不可触及的痛。

### 2.2 故事线：从小作坊到卖给雅虎→后悔终生

| 时间 | 事件 |
|------|------|
| 1998 年底 | 周鸿祎在城乡结合部马连洼租房创业——5 个人、几万元起家 |
| 1999 | 做出 3721 中文域名产品 |
| 2000 | 拿到 IDG 200 万美金 |
| 2000.3 | **微软与 Real Names 合作**——3721 借力微软，以为可以"一统天下" |
| 之后 | Real Names 倒下→3721 失去微软渠道 |
| 2003 | 卖给了雅虎——**"虚荣心大大膨胀"+"彼时的不自信又急于求成"** |

> "对于为什么会卖掉 3721：首先是竞争压力决定谈谈看——但提出收购的公司越来越多，周鸿祎虚荣心大大膨胀。加之彼时的不自信又急于求成，诸多因素混杂下就造成了 3721 这个十亿美金的教训。"

### 2.3 三大教训

| 教训 | 表现 |
|------|------|
| 借力不可靠 | 把命运托付给微软——微软随时可以甩掉你 |
| 急于求成 | 不够自信时就急于"上岸"——卖了就永远没有机会做大 |
| 没有大客户端 | 3721 本质上是个工具，不是平台——不像 QQ/淘宝具备网络效应 |

> "只要你有一个强大的客户端——如果你错过了，就永远错过了。"

## 案例三 港湾：资本的蜂拥与溃逃

### 3.1 李一男的出走与华为的"打港办"

| 时间 | 事件 |
|------|------|
| 2000.4 | 任正非在深圳五洲宾馆高调欢送李一男——**"最被广泛认为是任正非接班人"的人离职创业** |
| 2000—2003 | 港湾网络崛起——华为老员工纷纷加盟、风投蜂拥而至 |
| 2004 | **华为成立"打港办"**——全面围剿港湾 |
| 2006 | 港湾被华为收购——李一男回到华为 |

> "李一男被称为任正非的干儿子。但他与任正非最大的差距是——任正非已过多次风浪洗礼成为商业领袖，而李一男更多的只是位有技术专长和市场洞见力的创业家。"

### 3.2 港湾的三个教训

| 教训 | 表现 |
|------|------|
| 英雄≠领袖 | 李一男做决策时**潜意识都会设想任正非会怎么想**——永远活在前任的阴影里 |
| 资本是双刃剑 | 风投蜂拥而来→蜂拥而逃——"曾经被李一男看重并借力的风险资本，在最关键的时候，却成为轰其下台的帮凶" |
| 团队形不成合力 | "港湾梦幻管理团队没能在最需要团结的时候形成一支真正的团队" |

> "李一男想复制华为神话——不缺时机、不缺人才、不缺技术，唯独资金是个问题。但资本给了他资金，也给了他毁灭。"

## 案例四 盛大盒子：陈天桥的"自吟自唱"

### 4.1 最耀眼的明星，最惨烈的失败

> "如果盛大在 2005 年不做盛大盒子，今日的盛大乃至中国互联网将会怎样？可以肯定的是，盛大在网络游戏市场上的垄断性领先优势不会丧失。正是由于在盒子战略上倾斜性投入——盛大在网游市场上的领导地位衰落，客观上形成了今日网络游戏市场战国争霸的局面。**这是盛大的不幸，但却是行业的大幸。**"

| 时间 | 事件 |
|------|------|
| 2004 | 陈天桥=中国互联网最耀眼的明星——盛大上市，一周内发债募集 2 亿美金 |
| 2004 底 | 收购上游内容商 Actoz——信心极大修复 |
| 2005 春节 | 43 天斥资 20 亿→成为新浪最大股东——**"以相当夸张的方式提醒大众"** |
| 2005 | **推出盛大盒子**——"把客厅变成娱乐中心" |
| 之后 | 广电政策封杀→盒子失败→网游领导地位丧失 |

### 4.2 盛大盒子的三重错误

| 错误 | 表现 |
|------|------|
| 雄心凌驾团队 | 盒子是陈天桥**个人**的梦想——不是团队的共识 |
| 不考虑用户体验 | "完全不考虑用户的感受" |
| 时机不成熟+正面对抗强敌 | 与广电争夺市场——"在时机不成熟的时候与强敌交战" |

> "雄心是一个创业家应该具备的，但要想完成商业领袖的跨越，**克制自己的雄心（特别是当这个雄心与团队和市场不符的时候）** 却是一门必修课。盛大盒子是陈天桥企图从创业家跨越到商业领袖'自吟自唱'的玩具——但可惜未遂。"

## 案例五 8848：资本的冒进——从电商之巅到域名被抢注

### 5.1 王峻涛雪夜进京

> "1999 年元旦过后的第一个工作日，福州人王峻涛来到北京，带着做一个电子商务网站的商业计划。他是时任福州连邦的总经理。"

| 8848 的起点 | 优势 |
|-----------|------|
| 连邦连锁 | 近 300 个城市有专卖店——天然配送网络 |
| IT 产品供应链 | 完善的仓储和进销存系统 |
| 天时 | 中国最早做 B2C 的玩家之一 |
| 市盈率 | 1998 年底综艺股份成为连邦大股东——埋下祸根 |

### 5.2 资本毁掉一切

> "8848 这个故事本质上是一个内地上市公司资本、海外风险投资、本土产业资本以及一群梦想在互联网寻求机会的投资人、冒险家和投机客共同催生的泡沫故事。"

| 导致失败的因素 | 表现 |
|-------------|------|
| 综艺股份干预 | 上市公司大股东干预经营→"换一个玩法" |
| 资本冒进 | 过早引入过多资本→丧失控制权 |
| 错过最佳上市时机 | 折腾了两年最终没有上市——**阿里巴巴趁机崛起** |
| 2009 年域名被抢注 | "8848 域名已遭别人抢注，目前该域名直接指向淘宝网"——终极羞辱 |

> "穿过岁月的迷雾，8848 给我们留下的更多是关于坚持，关于抵抗诱惑，关于做回本我的经验教训。这样的经验教训，至今历久弥新，价值十亿美金。"

## 案例六 联想 FM365：一张一捅即破的饼

### 6.1 中国互联网第一浪的最大赢家——从资本市场的角度

| 数据 | 内容 |
|------|------|
| 1999 年 6 月 | 配股 1.3 亿股，拿回 9.36 亿港币 |
| 2000 年 2 月 | 配售 8500 万股，**圈走 28 亿港币**（新浪+网易+搜狐三大门户 IPO 募资加起来不到 2 亿美金） |
| 股价 | 1999 年初 2 港元多 → 一年涨近 30 倍 → 市盈率 250 倍以上（同期 IBM 约 20 倍） |
| 3 月 3 日 | 盈动合作消息传出，单日市值暴增 177 亿港元，总市值超 800 亿港元 |

> **"联想的互联网业务都是因资本而生，是热钱彻头彻尾的投机产物，最终在资本的压力下被抛弃也是理所应当——正所谓始乱必然终弃。"**

### 6.2 FM365 的"桶理论"与失败本质

> "联想提出一个桶的概念：门户网站很宽，但是太薄，一捅就破，像一张饼；专业网站像根管，内容很深，但是太细，有瓶颈效应。FM365 的目标是做一个**又宽又深的网站**——全才。"

| 失败原因 | 内容 |
|---------|------|
| 商业模式没问题但执行不到位 | "商业模式没问题只是成功的必要条件，不是充分必要条件，关键要看是否能执行到位" |
| 没有行动统一的团队 | 方礼勇/刘清涛等人才都在，但没有少帅型领军人物 |
| 因资本而生 | 28 亿港币圈到手，互联网业务"只见炊烟"——业绩撑不起 250 倍 PE |

> **投资启示：250 倍 PE 的概念股，无论背后是谁（哪怕联想），都是泡沫——"一个概念和一串运作，资本市场让柳传志坐上头等舱"，但头等舱落地时，没有真业务来接。**

## 案例七 ITAT：细节的错失

### 7.1 老欧的"三起三落"

| 阶段 | 事件 |
|------|------|
| 第一起 | 1982 年卖猪创业→金盾品牌→1998 年香港上市 |
| 第一落 | 亚洲金融危机→股价 1 毛钱→被国际游资恶意收购→两手空空回到原点 |
| 第二起 | 代理"幸运"品牌失败→转让商标品牌自救→2003 年收购法国国际商标集团 |
| 第三起 | 学沃尔玛做"服装业沃尔玛"→ITAT 疯狂扩张→上市未果→崩盘 |

### 7.2 ITAT 的三重原罪

| 原罪 | 表现 |
|------|------|
| 崇洋媚外式命名 | "像 ITAT 这样没节制无休止地滥用，甚至以此作为商业模式重要基石的，实属罕见" |
| 细节的错失 | 热气球比喻："一两个小细节的不注意就会葬送全局" |
| 领导人的"妖气" | "说不清道不明，雾里看花，把握不住，琢磨不透——这样的创业家断然无法具备商业领袖气质" |

> "从因果论来说，老欧的剑走偏锋和 ITAT 晚期在用户体验上细节重视不够，两者之间其实是因果关系：**有什么样的领导人，注定有什么样的企业做派。**因是因，果是果，因果其实早就注定。"

> **投资启示：看公司先看人——"琢磨不透"的创始人=不可投资的公司。商业模式能行得通（ITAT 模式至今仍有人做），但人不行，一切白搭。**

## 案例八 分众：热线的烦恼

### 8.1 江南春的"资本游戏"

| 事件 | 数据 |
|------|------|
| 2007 年 3 月收购好耶 | 2.25 亿美元 + 次年追加 7465 万美元 = **2.99 亿美元** |
| 2010 年出售好耶 | 1.24 亿美元卖给银湖 + 1330 万美元 MBO = **累计损失 1.61 亿美元** |
| 3·15 曝光 | 分众无线被央视曝光——"江南春主动断臂求生" |
| 50 亿→200 亿口号 | "在分众刚刚一跃成为 50 亿美金公司的关口，贸然提出成长为 200 亿美金的口号" |

### 8.2 分众失败的三个原因

| 原因 | 内容 |
|------|------|
| 没在中央系统上做文章 | 销售资源在"人"手里而不在平台手里→规模门槛；广告主端缺乏数据挖掘中心平台 |
| 团队建设不力 | "高层竟都是由被收购对象组成的"——一路收购，团队难磨合 |
| 创始人迷失 | "作为创始人不想着怎么把公司做实，而一味想着怎么在资本市场上圈钱" |

> **最扎心的悖论**："分众是个数十亿美金的教训，但江南春本人却由此收获了十亿美金的财富——他本质上是一个机会主义者，财务自由后内心没有成功的渴望，注定只能是个商人而已。"

> **投资启示：警惕"收购狂"公司——商誉积累、团队碎片化、创始人重心在资本运作而非经营。这正是 052 林奇"频繁再融资=四不碰"的公司画像。**

## 案例九 联众：决策无主

### 9.1 从三人开发组到被腾讯超越

| 时间 | 事件 |
|------|------|
| 1998 年春节 | 鲍岳桥+简晶+王建华（UCDOS"梦之队"）三人开始开发 |
| 1998 年 6 月 | 东方网景开放测试——5 个游戏，目标年底 200 人同时在线 |
| 早期尴尬 | 无人访问——"经常出现三个开发者共同陪一人玩的情形，或一人同时开三个 ID 扮演三个角色" |
| 巅峰之后 | 被腾讯超越——"鲍岳桥和联众在技术和产品上的良好感觉，改变不了约定俗成的用户习惯" |
| 2010 年 | MBO 完成，归属权问题解决，"迎来再度出发的契机" |

### 9.2 联众的三重困境

| 困境 | 内容 |
|------|------|
| 股权先天缺陷 | 中关村"智力入股"约定俗成——创始人股份偏少→融资后无法主导 |
| 决策无主 | "一直没有强大而统一的董事会，各方投资人和创始人貌合神离，决策一直处于无序状态" |
| 错失窗口 | 被腾讯用 QQ 用户习惯碾压——"有心杀贼，无力回天" |

> **投资启示：股权结构=公司治理的根基——"创始股份只有 5%"的 8848、决策无主的联众，本质上都是治理失败。A 股看公司，先看股权结构与实际控制人。**

## 案例十 PPG：断裂的链条

### 10.1 李亮与"衬衫直销神话"

## 附录四 知乎文风附录：十亿美金买来的三句话

> 2009 年，有人发现"8848.com"这个域名被抢注了——它直接指向淘宝网。
>
> 8848，中国电子商务的鼻祖，曾经的"电商之巅"。它的域名，如今成了竞争对手的流量入口。
>
> 这是林军《十亿美金的教训》里最残忍的一个画面。但残忍的远不止 8848：51.com 因为内讧把江山让给了腾讯；PPG 创始人留下一句"去美国发展"就失踪了；分众 50 亿美金的市值，最后变成了江南春个人的十亿美金。
>
> 十家公司，每家都曾经离"十亿美金"只有一步之遥。每家都亲手把这一步走成了十亿美金的教训。
>
> 读这本书，我最大的感受是：**商业失败从来不是"一个错误"，而是"一串错误"。**每一家公司的陨落，都能找到至少三个致命伤，而且它们总是同时发作：
>
> **第一，资本来得太容易，人就飘了。** 联想 FM365 圈走 28 亿港币——三大门户 IPO 加起来不到 2 亿美金。钱来得太容易，业务"只见炊烟"。股价一年涨 30 倍、市盈率 250 倍，业绩撑不起来，泡沫自然破。**投资里最危险的不是没有钱，是钱来得太容易。**
>
> **第二，创始人的人品，决定公司的天花板。** ITAT 的老欧"说不清道不明，雾里看花"，PPG 的李亮靠一个充满疑点的"51marry 经历"混进投资圈，分众的江南春"作为创始人不想着怎么把公司做实，而一味想着怎么在资本市场上圈钱"。**有什么样的领导人，注定有什么样的企业做派。因是因，果是果，因果早就注定。**
>
> **第三，链条生意，最怕断链。** PPG 的模式是供应商垫资、广告商垫资、VC 垫资——大家一起把车推上坡。竞争者一来，货压手里，投资商不给钱，链条从中间断掉，推车的人四散奔逃。**A 股里那些"经营现金流长期为负、靠融资输血"的公司，就是 PPG 的翻版。**
>
> 林军在书里反复提到巴菲特的一句话：**我们都是时间的孩子。**
>
> 时间会奖励踏实做事的人，也会惩罚所有想跳过过程直接拿结果的人。
>
> 8848 想跳过过程，直接上市；PPG 想跳过过程，直接称王；分众想跳过过程，直接 200 亿美金。结果呢？时间一个都没放过。
>
> 这本书的副标题是"十亿美金的教训"。但我更愿意把它读成：**十个创始人，用十亿美金，替我们交了学费。**
>
> 我们要做的，是别再交第二次。
