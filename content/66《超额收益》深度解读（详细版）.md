## 第1章 宏观不重要——"10 个经济学家 11 种观点"

> "有人在 2015 年伯克希尔股东大会上问巴菲特对美国宏观经济的看法——巴菲特说：'我实在想不起来，我曾经基于宏观经济因素而决定做过任何一桩买卖。'"

| 刘哲的宏观批判 | 数据支撑 |
|-----------|---------|
| **预测无效** | 2013年底中国各大券商给出2014年投资策略——上证涨53%——**没有一家预测准确** |
| **2015年惨案** | 兴业证券首席策略分析师5月28日喊"风险快速释放，继续干！"——6月股灾 |
| **宏观太复杂** | "同样的宏观数据，可以得出截然相反的结论——经济学界有一个难以摆脱的笑柄：10个经济学家会有11种不同观点" |

### 刘哲的宏观替代方案

| 不看这个 | 看这个 |
|---------|--------|
| GDP 增速预测 | 你关注的公司订单排到了什么时候 |
| CPI/PPI 走势 | 你关注的公司产品提价了没有 |
| 货币政策方向 | 你关注的公司融资成本是多少 |

> "宏观经济不是不重要——是对个股投资决策不重要。**你应该花时间研究公司，而不是预测 GDP。**"

## 第2章 选行业——朝阳可能是陷阱

### 2.1 刘哲的行业分类学

| 行业类型 | 特点 | 投资要点 | 案例 |
|---------|------|---------|------|
| **朝阳行业** | 高增长、前景好 | ⚠️ 如果进入门槛低→一窝蜂进入→竞争惨烈→**好赛道≠好投资** | 光伏/共享单车 |
| **夕阳行业** | 低增长、预期低 | ✅ 预期低=估值低+高股息→**股息再投回报也可能很高** | 烟草（吸烟人群下降但分红丰厚） |
| **资本密集型** | 需要大量资本支出/自由现金流低 | 估值不会太高——"赚的钱都投回去了" | 钢铁/重工业/房地产 |
| **轻资产型** | 投入少、现金流好 | 更容易产生高ROE——"用别人的钱做自己的生意" | 互联网/品牌消费品 |

### 2.2 选行业的四个关键问题

| 问题 | 分析要点 |
|------|---------|
| 行业的进入门槛高吗？ | "谁都能进的行业=谁都不赚钱的行业" |
| 行业集中度如何？ | "老大老二占70%=格局稳定 / 群雄割据=谁也赚不到钱" |
| 替代品威胁大吗？ | "高铁起来了→航空公司的利润就被压着" |
| 上下游议价能力？ | "供应商集中=被上游压价 / 客户集中=被下游压价" |

## 第3章 定性分析八大维度（全书最核心的板块，3.9万字）

| # | 维度 | 核心问题 | 刘哲的分析要点 |
|---|------|---------|------------|
| ① | **基础信息收集** | 公司是干什么的 | 年报/招股书/券商研报/实地调研——"多渠道交叉验证" |
| ② | **商业模式** | 怎么赚钱的 | 简单 vs 复杂——"最好的商业模式往往一句话能说清楚" |
| ③ | **护城河** | 为什么竞争对手抢不走 | 品牌/专利/网络效应/规模效应/转换成本 |
| ④ | **管理层** | 他们靠谱吗 | 诚信记录/持股比例/薪酬合理/历史业绩 |
| ⑤ | **竞争格局** | 对手是谁 | "如果明天来一个有钱的疯子砸钱——你的公司能扛住吗？" |
| ⑥ | **成长空间** | 天花板在哪 | 渗透率/市场规模/新业务线 |
| ⑦ | **产业链地位** | 上下游谁说了算 | 预收款（先收钱后发货）=强势 / 应收款大=弱势 |
| ⑧ | **风险因素** | 什么可能毁掉它 | 政策/技术替代/关键人物/单一客户 |

### 定性分析的核心心法

> "即使宏观和行业前景一片光明，但要投资的公司竞争力差——那么美好的前景和这家公司又有什么关系？**公司的研究是宏观和行业分析的最终落脚点。**"

## 第4章 定量分析六大体系（全书最实操的板块，6.3万字）

### 定量分析全景图

| 体系 | 关键指标 | 好公司的标准 |
|------|---------|-----------|
| **① 盈利能力** | ROE / 毛利率 / 净利率 / ROIC | ROE>15%持续5年以上 / 毛利率稳定或上升 |
| **② 成长性** | 营收增速 / 利润增速 / 现金流增速 | 3-5年连续增长——"不是某一年爆发" |
| **③ 财务健康** | 资产负债率 / 有息负债率 / 流动比率 | 有息负债越低越好——"欠银行的钱是最贵的钱" |
| **④ 运营效率** | 存货周转 / 应收周转 / 总资产周转 | 周转越来越快=管理越来越好 |
| **⑤ 现金流** | 经营现金流/净利润 / 自由现金流 | >1——"赚的钱真的进账了" |
| **⑥ 资本效率** | ROIC vs WACC | ROIC>WACC——"投资回报超过资本成本，才是在创造价值" |

### 刘哲的定量分析心法

> "财务分析的目的不是算出精确的数字——而是**判断趋势和发现异常**。连续三年的数据比一年的数据有价值一百倍。"

## 第5章 估值——四种方法全景

> "价值投资不见得必须持有伟大的公司——**关键是为此付出了多少溢价。归根结底，价值投资是投资付出的价格与得到公司的品质之间的性价比问题。**"

| 估值方法 | 适用场景 | 优点 | 缺点 | 刘哲的评价 |
|---------|---------|------|------|----------|
| **PE（市盈率）** | 盈利稳定的公司 | 简单直观 | 利润易操纵/周期股失效 | "最常用——但必须看利润质量" |
| **PB（市净率）** | 银行/保险/重资产 | 与资产挂钩 | 无形资产/品牌不体现 | "低于1不一定便宜——资产可能有毒" |
| **DCF（现金流折现）** | 现金流可预测的公司 | 理论最完整 | 假设多、误差大 | "更接近思维方式而非计算公式" |
| **PEG** | 成长型公司 | 兼顾增速 | 增长率靠猜 | "增长率预测=整个估值中最脆弱的一环" |

### 估值的两个难点

| 难点 | 刘哲的解答 |
|------|----------|
| **价值会变** | "在中国，很多公司短短几年就完成了国外几十年才完成的发展——价值变动剧烈" |
| **情绪包裹价格** | "市场大部分时间是有效的——只有当市场'出错'（恐慌或狂热）时，价值投资者才有机会" |

## 第6章 四种投资策略（全书最实用的板块）

| # | 策略 | 核心逻辑 | 适合 | 代表标的 |
|---|------|---------|------|---------|
| **① 低估绩优** | 好公司+低估值——"等市场发现它的价值" | 有耐心的人 | 被错杀的行业龙头 |
| **② 套利** | 要约收购/合并/重组——"赚确定性的差价" | 有计算能力的人 | 并购套利/可转债 |
| **③ 逆向投资** | 市场恐慌时买——"血流成河时买" | 心理素质强的人 | 行业危机中的龙头 |
| **④ 股息投资** | 高分红+稳定经营——"靠分红生活" | 追求现金流的人 | 公用事业/银行 |

## 总结：刘哲的完整操作模板

| 步骤 | 操作 |
|------|------|
| ① 不研究宏观 | "连巴菲特都不看——你研究什么？" |
| ② 选对行业 | 进入门槛高/集中度高/轻资产优先 |
| ③ 定性筛选 | 商业模式一句话能说清/有真护城河/管理层诚信 |
| ④ 定量验证 | ROE>15%+经营现金流>净利润+低有息负债 |
| ⑤ 合理估值 | PE合理或低估+留安全边际（至少20%） |
| ⑥ 构建组合 | 5-10只/3+行业/单只<20% |
| ⑦ 选择策略 | 低估绩优为主→套利为辅→逆向等机会 |

## 附录二 估值方法决策速查

| 你面对的公司是… | 用这个方法 | 注意 |
|------------|----------|------|
| 盈利稳定（消费/医药） | PE | 结合 ROE 判断利润质量 |
| 重资产（银行/地产） | PB | 看清资产里有没有"毒药" |
| 现金流可预测（公用事业） | DCF | 作为思维方式——不要精确到小数点 |
| 高增长（科技） | PEG | 增长率预测是最脆弱的一环 |
| 周期股（钢铁/化工） | 不用 PE——PE 最低时反而是最危险时 | 用 PB 或重置成本 |
