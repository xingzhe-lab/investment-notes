## 第4—5章 选基与投资技巧

### 5.1 资金期限匹配（本书独有亮点）

> "假如你手中有一笔钱，3个月后孩子要上大学——如果投进股票基金，短期面临调整被套，不得不取出来变现，浮亏就变成实实在在的损失。这就叫资金错配。"

| 资金期限 | 适合的基金类型 |
|---------|-------------|
| <3 个月 | 货币基金 |
| 3 个月—1 年 | 短债/纯债基金 |
| 1—3 年 | 混合债基/偏债混合 |
| **3 年以上** | **股票型/偏股混合** |

### 5.2 货币基金选购要点

| 要点 | 内容 |
|------|------|
| 成立时间 | 越长越成熟 |
| 基金公司 | 大公司更专业安全 |
| 规模 | 太小→赎回困难，选大规模更稳妥 |

## 第6章 基金新势力（本书最大差异化价值）

### 6.1 指数基金——巴菲特的世纪赌局

> "2005年巴菲特提出50万美元公开赌约：主动管理基金10年跑不赢标普500指数。" 2008年基金经理泰德·西德斯接受挑战，2017年认输——**标普500大胜。**

| 指数基金分类 | 说明 |
|------------|------|
| 宽基指数 | 沪深300/中证500/创业板指（覆盖面广） |
| 窄基指数 | 行业（医药/消费）/主题（新能源）/策略（红利/低波） |
| 场内（ETF） | 交易所交易，像股票一样买卖 |
| 场外 | 银行/基金公司/互联网平台申购 |

### 6.2 ETF——场内交易的利器

| ETF 优势 | 内容 |
|---------|------|
| 交易灵活 | 盘中实时交易，不像场外基金只按收盘净值 |
| 费用低 | 管理费通常 <0.5% |
| 透明度高 | 每日公布持仓 |
| 品种丰富 | 股票/债券/商品/跨境/行业 |

### 6.3 养老目标基金——为自己的退休生活做准备

> "郑先生老两口在工作期间就购买了养老主题基金，现在取得了非常不错的收益，加上退休工资，一点压力都没有。"

| 养老基金特点 | 内容 |
|------------|------|
| 目标日期型 | 根据退休年份自动调整股债比例（如"XX2050养老"） |
| 目标风险型 | 固定风险水平（保守/稳健/进取） |
| FOF 形式 | 基金中的基金，二次分散 |
| 封闭期 | 通常 1/3/5 年，鼓励长期持有 |

### 6.4 REITs——不动产投资的新通道

| REITs 特点 | 内容 |
|-----------|------|
| 投向 | 基础设施（高速/仓储/产业园/保障房） |
| 收益 | 强制分红（90%+可分配利润） |
| 流动性 | 交易所上市交易 |
| 适合 | 想投不动产但不想买房的投资者 |

## 第7章 定投：从微笑曲线到真实数据

### 7.1 定投的历史

| 时间 | 事件 |
|------|------|
| 1949 | 格雷厄姆《聪明的投资者》提出"美元成本平均法" |
| 1983 | 台湾第一只开放式基金 |
| 1992 | 台湾大力发展定投（普及率接近 50%） |
| 2000 | 香港"强积金"（基金定投 101 计划） |
| 2005 | 中国内地出现基金定投 |
| 2008 | 市场大跌后定投进入快速发展 |

### 7.2 定投真实效果（A 股 3000 点测试）

**（本书做了定量的定投效果测试——以中证偏股型基金指数为标的，在沪指 3000 点附近的不同时点开始定投）**：

| 开始定投时间 | 市场特征 | 定投结果 |
|------------|---------|---------|
| 2008.6（3000 点） | 熊市中途 | 定投后继续跌→积累大量低位份额→反弹后正收益 |
| 2010.4（3000 点） | 震荡 | 平滑成本→温和正收益 |
| 2015.8（3000 点） | 股灾后 | 分批买入→摊平成本→正收益 |
| 2018.6（3000 点） | 熊市中 | 持续定投→低位吸筹→2019-2020 大涨 |

**结论**：**3000 点开始定投，无一例外都在后续市场回升中实现了正收益。**

> "市场诡谲多变，想要做到完美的'高抛低吸'几乎不可能。定投不是战胜市场的万能药，却是一个提高胜率的好方法。"

### 7.3 邹女士的故事

> "2015年市场急速下跌，邹女士积累的收益都亏没了——但她决定继续坚持。后来市场回升，离孩子的创业金目标越来越近。她说：'我现在十分感谢定投，也感谢自己的坚持。'"

## 第8章 构建基金组合

### 8.1 "不可能三角"的优化

| 三角 | 取舍 |
|------|------|
| 高流动性 | 随时可赎回 |
| 高安全性 | 不亏损或微亏 |
| 高收益性 | 追逐超额回报 |

**单一产品不可能三者兼得。但通过组合可以**——用不同风险收益特征的基金搭配，逼近"有效前沿"。

| 组合基金数量 | 效果 |
|------------|------|
| 1 只 | 收益波动大 |
| 5 只 | 收益分布收窄 |
| 10 只 | 收益大概率接近均值——**确定性大大提高** |
| 20 只 | 进一步收窄（但边际递减） |

### 8.2 分散的四个维度

| 维度 | 分散什么 |
|------|---------|
| 资产 | 股票/债券/商品/海外 |
| 行业 | 医药/消费/科技/金融 |
| 风格 | 大盘/小盘/价值/成长 |
| 管理人 | 不同基金经理/不同基金公司 |

## 第9章 基金投资风险

### 9.1 系统性 vs 非系统性风险

| 类型 | 定义 | 基金能否消除 |
|------|------|------------|
| 系统性 | 政策/国际形势/经济周期 | **不能**——所有基金都受影响 |
| 非系统性 | 个股/个别债券问题 | **能**——通过分散投资消除 |

> "基金可以最大限度消除非系统性风险，而系统性风险是基金主要暴露的风险。"

### 9.2 基金的独特风险来源

| 风险源 | 内容 |
|--------|------|
| 产品定位 | 不同类型的风险天然不同（股基>债基） |
| 基金经理 | 人的主观判断可能出错——基金经理不是万能的 |
| 流动性 | 赎回潮时可能被迫低价变现 |

## 第10章 基金绩效评估（全书最独特的价值）

### 10.1 "近3年"的陷阱

> "你买了一只近3年净值翻番的基金，为何最近亏得一塌糊涂？因为所谓的'近3年收益率'可能只是3年里某一年甚至某几个月剧烈上涨的结果——不能反映过去3年的稳定增值。"

| 常见陷阱 | 说明 |
|---------|------|
| "近3年翻倍" | 可能是 3 年前某一年暴涨+后两年平平或亏损 |
| 基金经理变更 | 前任创造的业绩与现任无关——买的是现任的未来 |
| 行业爆发期 | 2021 年底看过去 3 年新能源基金全涨——**然后买在山顶** |

### 10.2 正确看绩效的方法

| 方法 | 操作 |
|------|------|
| 拉长期限 | 不全看 3 年——看 5 年、各年度收益 |
| 分年看 | 看每年（而非累计）的收益——有没有大起大落 |
| 分市场看 | 牛市中表现 vs 熊市中表现 vs 震荡中表现 |
| 同类窄比 | "消费主题基金"只在消费主题里比——放在全市场比没意义 |

### 10.3 排名不是万能的

> "某二级债基 8 成买了可转债——风险收益特征和其他二级债基完全不同。主投美股的 QDII 和主投港股的 QDII 经常放在同一个分类里排名——可比性很低。"
