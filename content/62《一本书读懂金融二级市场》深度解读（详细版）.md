# 62《一本书读懂金融二级市场》深度解读（详细版）

> **副题：邢恩泉——"从业人员访谈录"：行业研究员/卖方/买方/量化/FOF/银行金融市场——二级市场各类岗位的工作日常与入行指南**
>
> 本书是 26 位金融二级市场从业者的访谈合集，覆盖三大板块：**职业体验**（研究员/私募/公募/银行金融市场的工作日常）、**业务扫盲**（食品饮料/新能源/生物医药/量化/FOF 的投资框架）、**入行指南**（转行/求职/进阶路径）。
>
> **核心定位**：系列中唯一的"金融职业指南"——不是教你投资，是教你怎么进入投资这个行业。适合想转型金融的读者。

---

## 📖 全书三部分速览

### 第一部分：各类岗位真实体验

| 岗位 | 一句话 |
|------|--------|
| **行业研究员** | 拆财报→跑调研→写报告→路演——"一半时间在路上" |
| **营业部负责人** | 证券零售=获客+服务+合规——"最重要的是信任" |
| **卖方研究** | "申万体系"的层次与框架——宏观→策略→行业→公司 |
| **银行金融市场部** | 债券/外汇/衍生品——"比券商更稳健、比基金更全面" |
| **私募基金** | 更少的条框、更大的压力——"业绩就是一切" |
| **公募→私募转型** | "公募教你规矩，私募考验能力" |

### 第二部分：各行业投资逻辑

| 行业 | 核心投资逻辑 |
|------|-----------|
| **食品饮料** | 品牌护城河+提价能力+渠道壁垒——"嘴巴相关的东西最抗周期" |
| **新能源** | 技术迭代快→细分赛道差异大：光伏/风电/锂电/储能各有逻辑 |
| **生物医药** | 管线估值→创新药/仿制药/CXO/医疗器械——"专业壁垒最高的行业" |
| **FOF** | 基金中的基金——选基金+配置+风控——"为不专业的钱做专业的事" |
| **量化投资** | 数据+模型+回测→"用数学打败情绪"——门槛最高但增长最快 |

### 第三部分：入行路径

| 背景 | 转型建议 |
|------|---------|
| 互联网→金融 | 技术功底是优势→补充金融知识+考证（CFA/FRM） |
| IT→金融科技 | 量化/算法交易/风控系统——"金融科技是蓝海" |
| 应届生 | 实习>证书>学历——"先入行再选择方向" |
| 卖方→买方 | "卖方教你写报告，买方教你管钱"——3-5 年卖方经验后跳买方是经典路径 |
