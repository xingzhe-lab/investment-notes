# 营收少了12%，利润却涨了47%！中国稀土这份半年报藏着什么秘密？

营收少了12%，利润却涨了47%！中国稀土这份半年报藏着什么秘密？

源网页

公众号名称：科学书

作者名称：科学书

发布时间：2026-08-09 00:01

2026年8月7日，中国稀土披露了一份让很多人看不懂的半年报。

营业收入16.47亿元，同比下降12.19%——嗯，生意在缩水。归母净利润2.37亿元，同比大涨46.53%——等等，收入少了，赚的钱反而多了？

更夸张的是，经营活动现金流净额从去年同期的-4560万元，直接翻转为净流入7.11亿元。

这就像一家餐厅，客流少了12%，但净利润涨了将近一半，收银台里的现金还多出了好几个亿。反常吗？反常。但拆开来看，逻辑并不复杂。

# 一、利润狂奔的秘密：主动“砍业务”

先说结论：这不是被动衰退，是主动瘦身。

公司自己说得明白——“调整采销策略，优化产品结构和贸易业务”。翻译成大白话就是：砍掉不赚钱的买卖，留下能赚钱的部分。

具体怎么砍的？来看数据：

稀土氧化物：收入12.82亿元，同比增长7.68%，营收占比从63.51%提升到77.88%。稀土金属及合金：收入从6.74亿元腰斩至3.53亿元，降幅47.60%，占比从35.95%降到21.46%。

公司主动放弃了近一半的金属及合金业务规模，把资源向稀土氧化物集中。

结果呢？整体毛利率从去年同期的13.37%飙升到22.41%，提升了9个百分点。被砍掉的那块业务——稀土金属及合金——毛利率反而跃升了14.54个百分点，达到21.44%。

砍掉的正是那些没有议价权、靠规模走量的低价贸易订单。留下来的，才是真正能挣钱的。

# 二、价格周期的东风：镨钕大涨73.6%

光靠内部调整还不够，外部也得给力。

2026年上半年，稀土行业赶上了一波好行情。据中国稀土行业协会数据，上半年氧化镨钕平均价格为73.1万元/吨，同比大涨73.6%。

公司半年报也确认了这一点：“受稀土产业政策、下游市场需求提振等多重有利因素影响，市场行情整体上行，镨钕产品价格较去年同期涨幅明显”。

供给端也在收紧。海关数据显示，2026年5月我国稀土矿进口量同比下降44.4%；回收端受税收政策影响，6月再生氧化物产量环比缩减19.5%。进口少了、回收少了、国内管控严了，价格自然往上走。

内部砍低毛利业务 + 外部赶上价格上涨周期 = 营收降了、利润反而大涨。

# 三、现金流暴增1658%：真金白银回来了

还有一个数据值得单独说——经营现金流暴增1658%。

从净流出4560万到净流入7.11亿，这背后是两件事：一是销售回款能力大幅增强，卖出去的东西钱收回来了；二是消耗了年初的库存备货，采购支出减少了。

简单说：不光账面赚钱，是真金白银落袋了。

# 四、隐忧一：研发投入大幅下滑31.55%

说完好的，说说担心的。

研发费用同比减少31.55%。公司在财报中解释是“子公司新增研发项目投入相对缓慢”。

稀土行业拼的是技术——冶炼分离的纯度、新材料的开发、成本的优化，哪个不需要研发投入？在行业景气度高的时候砍研发，短期看省了钱，长期看可能是透支未来。

有业内人士向《证券日报》表示，公司净利润走高“既是企业主动调结构的成果，也折射出2026年国内稀土行业供给收紧、价格分化的产业现状”。但研发投入的下滑，提醒我们这份成绩单并非没有隐忧。

# 五、隐忧二：核心矿山“探转采”卡了三年半

更大的隐患在矿山端。

公司旗下圣功寨稀土矿的“探转采”工作，自2022年5月《矿山地质环境保护与土地复垦方案》通过部级审查后，至今已逾三年半，采矿权证仍未获批。

有投资者在互动平台直接质问：行业内同类项目审批周期明显更短，集团内部其他公司的采矿权已陆续取得，为什么圣功寨迟迟批不下来？

公司的回复是：“组建了工作专班加快推进圣功寨稀土矿探转采办理等相关工作”。

三年半拿不到采矿权证，这不是小问题。 如果这座矿山迟迟不能投产，公司的资源自给率就会持续承压，未来业绩对集团资产注入的依赖度会越来越高。

另外，2026年7月，凉山州生态环境局还对公司的牦牛坪稀土矿开出了行政处罚决定书，原因是“新建稀土萤石混合精矿强磁选分离工艺优化项目未取得环境影响评价批复文件”。

合规瑕疵是悬在公司头顶的一把剑。

# 六、未来最大的变量：集团资产注入

那公司未来的业绩弹性靠什么？

资产注入。

2022年1月，中国稀土集团承诺2027年1月底前完成相关资产注入，解决同业竞争。

2026年4月，公司在回应投资者时明确表示：“正积极配合中国稀土集团开展解决同业竞争问题的相关工作，择机开展并购重组”。

2026年年初，中国稀土集团还通过无偿划转方式，完成了对广晟有色38.45%股权的实际控制，进一步强化了对南方中重稀土资源的掌控力。

中信证券研报预计，2026年起全球稀土供需缺口将持续扩大——2026年缺口约0.9万吨，2027年扩大到1.3万吨，2028年扩大到2.1万吨。新能源汽车、风电、工业机器人，加上人形机器人商业化加速，都在持续拉动稀土需求。

价格周期向上 + 集团资产注入预期 = 中国稀土最大的想象空间。

但也要清醒：资产注入的节奏受政策审批影响，存在不确定性；圣功寨采矿权证什么时候能批下来，也是个未知数。

总结一下

这份半年报的核心信息就一句话：公司通过主动收缩低毛利业务，叠加镨钕价格上涨周期，实现了“减收增利” 。现金流大幅改善是实实在在的亮点，但研发投入下滑31.55%和矿山合规瑕疵是两个不容忽视的隐忧。

未来业绩弹性，高度依赖两件事：集团资产注入的节奏、稀土价格的周期走向。

前者看政策，后者看供需。2026年氧化镨钕均价已经站上73万元/吨的历史高位，未来能否持续，需要持续跟踪。
