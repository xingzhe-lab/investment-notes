## 第1章 集合竞价：开盘前的博弈

### 1.1 9:15—9:25 发生了什么

| 时间段 | 规则 |
|--------|------|
| 9:15—9:20 | 可申报/可撤单（**主力常挂大单试盘后撤单**） |
| 9:20—9:25 | 只能申报/**不能撤单**（真实的买卖意愿） |
| 9:25 | 产生开盘价（**最大成交量原则**） |

### 1.2 集合竞价的看盘要点

| 信号 | 含义 |
|------|------|
| 竞价阶段买单持续增加 | 开盘可能高开，做多意愿强 |
| 竞价阶段卖压增大 | 低开概率大 |
| 最后 1 分钟价格跳变 | **主力操纵竞价——试盘行为** |
| 挂涨停价买/跌停价卖 | 保证优先成交 |

> "散户希望在集合竞价时优先买到股票，可以把价格打得高一些——目的是获得优先成交权。"

## 第2章 尾盘急拉与跳水：收盘前的暗战

### 2.1 尾盘急拉（"偷尾盘"）

| 尾盘拉升目的 | 判断 |
|------------|------|
| 吸筹（低位） | K线低位+首日拉升+量能放大→**可跟进过夜** |
| 出货（高位） | 连续多日上涨后的尾盘拉升→**散户别参与过夜** |
| 做K线形态 | 最后半小时拉出一根光头阳线→**第二天出货的前奏** |

> "主力不会选择在盘中拉升——需要大量护盘资金。尾盘偷袭既达到拉高目的，又节省上拉成本。"

### 2.2 尾盘跳水

| 类型 | 判断 |
|------|------|
| 真出货 | 高位+放量+持续多日 |
| **洗盘（假跳水）** | 全日走势良好→尾盘突然砸盘→**第二天低开高走甚至涨停** |

> "如果是非理性的下跌，下跌的又是龙头股，那么第二天高开的机会增大，投资者可考虑在最后一分钟买进。"

## 第3章 葛兰碧量价八法：成交量的语言

### 3.1 量价关系速查

| # | 量价组合 | 含义 |
|---|---------|------|
| 1 | 量涨价涨 | 健康上涨，有价有市 |
| 2 | 量涨价涨但量未创新高 | **潜在反转信号** |
| 3 | 价涨量缩 | 上涨动力不足→警惕反转 |
| 4 | 量剧增+价暴涨→量剧缩+价暴跌 | 涨势末期，井喷后必反转 |
| 5 | 量增价滞涨（高位） | 卖压沉重→**即将下跌** |
| 6 | 量增价不跌（低位） | **即将反转上涨——买入机会** |
| 7 | 谷底反弹量不跟→再跌回谷底→第二谷底量更小 | **底部确认，即将上涨** |
| 8 | 跌破均线+大成交量 | **下跌信号** |

### 3.2 实战中的量价操作

| 态势 | 操作 |
|------|------|
| **低量低价** | 见底信号——但不急于买入，等基本面确认 |
| **量增价平（低位）** | 新资金打压建仓→一旦掉头向上=底部形成 |
| **量增价涨** | 上升初期/中期——持股 |
| **量缩价涨** | 主力控盘或高位出货——观望 |
| **量增价跌** | 下跌初期——减仓 |

## 第4章 主力进场：四信号识别

### 4.1 主力的四个特征

| 信号 | 内容 |
|------|------|
| **低点不断抬高** | 最强烈的进场信号——连续3个以上低点上移=主力成本线 |
| **大涨小回** | 跌时抗跌/涨时强于大盘——"洗得越凶，涨得越猛" |
| **横盘代替调整** | 大盘跌它不跌——主力担心丢失筹码 |
| **利多利空反应异常** | 出利好不涨→主力在出货；出利空不跌→主力在吸筹 |

### 4.2 三种可持有的股票形态

| 形态 | 操作 |
|------|------|
| 买点线 | 股价跌到某位置必反弹→战略性买进 |
| 主力成本线 | 连续3个不断抬高的低点连接线→持有 |
| 趋势线 | 20/30日线之上→不破不卖；破3周不收回→逢反弹卖 |

## 第5章 涨停板操盘：一字/T字/实体

### 5.1 三种涨停类型速查

| 类型 | 特征 | 操作 |
|------|------|------|
| **一字板** | 全天一个涨停价/量大封单/买不到 | 别追——等回调 |
| **T字板（强势）** | 涨停开盘→瞬间打开→立刻封回 | 等相对低位 |
| **T字板（反复打开）** | 涨停板反复开合→多空争夺 | **别参与**——换手率大=庄家出货 |
| **实体板** | 低开→盘中拉至涨停 | **最健康的涨停**——配合消息可顺势短线 |

### 5.2 追涨停的六条法则

| 法则 | 内容 |
|------|------|
| 极强市场追/极弱市场不追 | 日均 5 只涨停以上才考虑 |
| 追龙头不追跟风 | 先涨停>后涨停；有跟风>无跟风 |
| 不到涨停不追 | 涨幅 9% 以上备好买入，防主力大单封死 |
| 量不能太大 | 当日量为前日 1-2 倍为宜 |
| 第一个封涨停最好 | 10:10 前涨停最可靠（盈利概率 80%） |
| 下午涨停不追 | 跟风庄家，封盘不坚决 |

## 第6章 看盘口诀：散户的速成心法

### 转强换手篇
> "要想涨，先有量。由跌转涨量先强，百分之三是标准。百分之五不能追，要等回拉靠线莫心慌。十五以上要谨慎，三十以上要提防，三日没有新高现，只卖不买没商量！"

### 转强追涨篇
> "一日长量先看看，二日长量要紧张，三日长量是反转，马上追涨没商量！"

### 盘中买卖篇
> "量比超过2.5，主力开始动手了。上来先冲3.5，千万别急乱追涨。回落不缩量，反身再冲上，打横走一走，买它没商量。"
